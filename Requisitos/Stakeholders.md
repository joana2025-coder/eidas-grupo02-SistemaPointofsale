# Stakeholders

## Sistema Point of Sale (POS) - Bar Carrefour

| Stakeholder | Tipo | Función en el sistema |
|---|---|---|
| Encargadas | Usuario directo | Operan el sistema para gestionar mesas, pedidos y cobros. |
| Mozas | Usuario indirecto | Atienden a los clientes y transmiten los pedidos a las encargadas. |
| Dueño | Interesado | Supervisa el funcionamiento y controla las ventas. |
| Técnico de Soporte | Soporte técnico | Realiza el mantenimiento y la resolución de problemas del sistema. |
| Clientes | Externos | Consumen productos y realizan pagos. |
